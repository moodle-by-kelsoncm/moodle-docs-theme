moodle-docs-theme
===================

Tema Sphinx reutilizável, inspirado visualmente na documentação oficial do Moodle
(`docs.moodle.org <https://docs.moodle.org/>`_): cabeçalho claro com faixa de destaque
laranja, títulos em roxo, links em azul e barra de contexto secundária — a mesma
linguagem visual do MoodleDocs, adaptada para documentação de plugins e temas Moodle
mantidos por organizações no GitHub.

Esta é a própria documentação do tema, construída com o tema que ela documenta.

Por que este tema existe
-------------------------

Projetos Moodle (temas, blocos, plugins) costumam documentar via Sphinx usando temas
genéricos como o Read the Docs, que não guardam nenhuma relação visual com o ecossistema
Moodle. O ``moodle-docs-theme`` existe para que toda a documentação de plugins e temas de
uma organização compartilhe a mesma identidade visual do MoodleDocs, sem repetir CSS em
cada repositório.
