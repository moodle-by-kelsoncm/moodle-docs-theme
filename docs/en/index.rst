moodle-docs-theme
=================

Reusable Sphinx HTML theme visually inspired by official Moodle documentation
(`docs.moodle.org <https://docs.moodle.org/>`_): light header with orange accent
stripe, purple titles, blue links, and secondary context bar — the exact visual language
of MoodleDocs, tailored for Moodle plugins and themes maintained on GitHub.

This is the theme's own documentation, built with the very theme it documents.

Why this theme exists
---------------------

Moodle projects (themes, blocks, plugins) often document using generic Sphinx themes
such as Read the Docs, which lack visual connection to the Moodle ecosystem.
``moodle-docs-theme`` enables all organization plugins and tools to share the same visual
identity as MoodleDocs, without duplicating styles across repositories.
